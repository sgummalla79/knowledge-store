Get a free Voyage API key

Voyage AI provides a free tier that covers embedding and re-ranking — no credit card required. Follow the steps below to get your key.

1

Create a free Voyage AI account

Go to dash.voyageai.com and sign up with your Google or GitHub account (or email). No credit card is asked during sign-up.

2

Open the API Keys page

After signing in, click API Keys in the left sidebar (or navigate to dash.voyageai.com/api-keys).

3

Create a new key

Click Create new secret key, give it a name (e.g. Knowledge Store), then click Create. The key starts with pa-.

4

Copy the key immediately

The full key is shown only once. Copy it now — you will not be able to view it again after closing the dialog.

5

Paste it here

Close this panel, expand the Embeddings — Voyage card, paste your key into the API key field, and click Save key. It's stored in the database and never shown again.

Free tier limits — Voyage AI's free plan includes 200M embedding tokens and 1M re-ranking tokens per month, more than enough to get started. Upgrade any time from the Voyage AI dashboard if you need higher limits.
Which model is used? — Knowledge Store defaults to voyage-3 for embeddings and rerank-2 for re-ranking, both covered by the free tier. You can change the rerank model in the Search & rerank section inside this same card after your key is saved.
